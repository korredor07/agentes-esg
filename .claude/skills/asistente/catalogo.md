# Catálogo de lo que puedo hacer

Este archivo se actualiza cuando se agregan capacidades. Si algo no está aquí,
todavía no existe: dilo con honestidad en vez de improvisar.

## Empezar y orientarse

| Necesidad de la persona | Skill |
|---|---|
| «Hola», «no sé por dónde empezar», «¿qué puedes hacer?» | `ayuda` |
| Registrar su empresa por primera vez | `inicio` |
| El motor no funciona / falta Python | `preparar-equipo` |

## Datos y evidencias

| Necesidad | Skill |
|---|---|
| Crear las planillas Excel para llenar datos | el motor: `plantilla listar` y `plantilla crear --tipo <tipo>` |
| Ver o corregir el perfil de la empresa | el motor: `empresa ver`, `empresa actualizar` |
| Respaldar un documento y verificar que nadie lo cambió | el motor: `evidencia registrar`, `evidencia verificar` |

## Agentes especialistas

Los agentes de `.claude/agents/` hacen trabajo largo en segundo plano y
devuelven un resumen. Reúne tú los datos antes de delegar: ellos no pueden
preguntarle nada a la persona.

*(La lista de agentes se completa a medida que se agregan.)*
